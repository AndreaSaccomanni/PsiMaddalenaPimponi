# Convenzioni del progetto

- `README.md` è la guida unica del progetto ed è incluso nella soluzione Visual Studio (cartella *Solution Items*). Va aggiornato **ogni volta** che una modifica cambia il funzionamento del sito: pagine, modulo contatti, invio email, sicurezza, metadati, configurazione o pubblicazione. Aggiungi anche una riga in "Cronologia delle funzionalità".
- Le modifiche solo estetiche (colori, spaziature, immagini decorative) non richiedono una riga di cronologia, ma se cambiano il modo in cui si modificano i contenuti il README va comunque allineato.
- Il README è scritto per una persona senza formazione tecnica: i termini tecnici vanno spiegati, non solo citati.
- Commit e merge li gestisce il proprietario del repository. Non committare né aprire pull request senza una richiesta esplicita.
